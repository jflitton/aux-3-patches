; A/UX Toolbox (user-mode Mac environment) changes for the Quadra 605.
; Apply with tools/binpatch.py. Written against A/UX 3.1 (AWS 95) /mac/lib/Patches.

; GetLowFromKernel saves the kernel's BoxFlag in realBoxFlag (Gestalt 'mach' = it + 6) and
; then rewrites BoxFlag to 0x10 (Quadra 700) for the machines System 7.0.1 predates
; (0x18 C650, 0x1D Q800, 0x1E Q650, 0x2E C610, 0x2F Q610, 0x35), because the System's
; 'boot' 2 resource refuses any BoxFlag above 0x14 with SysError(102), "This startup disk
; will not work on this Macintosh model". Add the 605: 0x58 at 25MHz, 0x59 at 33MHz (the
; ROM picks the record by the CPU ID register, $2225 / $2226). The second, redundant load
; of BoxFlag into d0 makes room for the two tests; the range check that follows is the
; same with word operations (the jump table indexes with d0.w), and ends on the original
; bhi.b at +0x4e.
file /mac/lib/Patches/Patch.067C
at GetLowFromKernel+0x3a   ; was: move.b BoxFlag,d0; extb.l d0; subi.l #$18,d0; cmpi.l #$1d,d0
check 7fb300a60401f333
new 0c 00 00 58            ; cmpi.b  #$58,d0          d0 = BoxFlag already
new 67 ca                  ; beq.b   GetLowFromKernel+0xa (BoxFlag = 0x10)
new 0c 00 00 59            ; cmpi.b  #$59,d0
new 67 c4                  ; beq.b   GetLowFromKernel+0xa
new 04 40 00 18            ; subi.w  #$18,d0
new 0c 40 00 1d            ; cmpi.w  #$1d,d0
